# 🐾 Veterinaria CLI - Gestión de Citas

Este proyecto es una aplicación de consola desarrollada en **Node.js** que permite registrar y consultar citas de una veterinaria de forma sencilla, almacenando la información en un archivo JSON.

---

## 📌 Descripción

La aplicación permite:

- Registrar nuevas citas de mascotas
- Leer todas las citas almacenadas
- Persistir la información en un archivo `citas.json`

Todo se ejecuta desde la terminal usando argumentos.

---

## ⚙️ Tecnologías utilizadas

- Node.js
- File System (fs)
- JSON como base de datos local
- JavaScript
